# API-001: Sensitive Data in Logs

## Branch

`feature/api-logging-sensitive-data`

## Category

Security / Logging

## Severity

High

## Expected Finding

The API logs sensitive request data (such as authorization headers or bearer tokens) that should be excluded or redacted.

## Expected Location

`src/Api/Program.cs`

## Good Reviewer Behavior

The reviewer should flag sensitive logging and recommend removing or redacting the data.

## Do Not Require

- Exact wording
- Exact line number
- A specific code fix
